Motivation

Why This Project?

Lagos is a densely populated coastal city that experiences sudden rainfall, high humidity levels, and rapidly changing weather patterns throughout the year. For millions of residents, outdoor drying of clothes is a daily necessity — yet the unpredictable weather makes effective planning very difficult.

"Instead of simply showing users the weather, the system helps answer a practical question: Can my clothes dry outside today?"

This application addresses the gap between raw meteorological data and actionable household decisions by implementing a deterministic scoring engine that converts weather forecast information into a clear, personalized laundry recommendation.

The Problem

  • Sudden and unpredictable rainfall
  • High ambient humidity levels
  • Rapidly changing weather conditions
  • Uncertain outdoor drying conditions
  • Weather data not translated into action

The Solution

  • Real-time weather analysis engine
  • 0–100 drying suitability score
  • Rain-risk assessment
  • Best drying window identification
  • Fabric-aware drying-time estimation
  • Multi-location Lagos comparison

Technical Process

How the System Works

01
Select Location
User selects one of Lagos State's 20 Local Government Areas for hyper-local data retrieval.
02
Get Forecast
The app fetches current and hourly weather data from the Open-Meteo API for the selected location.
03
Analyse Conditions
Temperature, humidity, wind speed, rain probability and precipitation are extracted and processed.
04
Calculate Score
A deterministic algorithm produces a 0–100 drying suitability score from the weighted weather factors.
05
Generate Recommendation
The engine outputs a clear recommendation: Excellent, Good, Moderate, or Poor — with a reason.
06
Identify Best Window
A sliding-window scanner identifies the optimal consecutive hours of safe, daylight outdoor drying.

Core Algorithm

The Drying Score

The drying score is a deterministic value between 0 and 100 that combines temperature, humidity, wind speed, rain probability and precipitation into a single actionable indicator. Each factor is weighted according to its relative impact on outdoor evaporation.

90–100
Excellent
70–89
Good
50–69
Moderate
0–49
Poor

Note: If precipitation exceeds 1.0 mm or rain probability reaches 70%, the score is automatically capped at 40 regardless of other conditions.

Application Features

Core Features

Laundry Recommendation

Clear Excellent / Good / Moderate / Poor recommendations driven entirely by real-time weather data.

Drying Score

A 0–100 algorithm combining temperature, humidity, wind and rain factors into a single decision metric.

Rain Risk Prediction

Evaluates rain probability and precipitation to assess whether outdoor laundry is safe.

Best Drying Window

Scans the next 24 hours to identify the optimal consecutive dry daylight period for outdoor drying.

Smart Drying Timer

Estimates how long clothes will take to dry based on fabric type, washing method, load size and weather.

Fabric Intelligence

Adjusts drying time estimates per fabric: Cotton, Jeans, Towels, Silk, Synthetic, Linen and more.

Lagos LGA Support

All 20 Lagos State Local Government Areas are supported with precise GPS coordinates.

16-Day Forecast Calendar

Displays a multi-day forecast calendar identifying the single best upcoming laundry day.

Location Comparison

Simultaneously compares drying conditions across multiple Lagos LGAs to find the best spot.

What-If Simulator

Interactive sliders let users manually adjust weather inputs and observe live algorithm responses.

Laundry History

Saves past laundry plans to localStorage and presents usage statistics for review.

Push Notifications

Optional browser notifications alert users when a drying window opens or rain risk increases.

Progressive Web App

Installable as a home-screen app on any device via the Web App Manifest standard.

Offline Support

A Service Worker caches all assets so the application shell loads even without internet access.

Project Objectives

  1. Analyze localized Lagos weather forecast data.
  2. Determine suitable outdoor laundry conditions.
  3. Calculate a weather-based drying score.
  4. Identify safe consecutive drying windows.
  5. Estimate fabric-specific drying duration.
  6. Provide personalised laundry recommendations.
  7. Compare weather conditions across Lagos LGAs.
  8. Deliver a responsive, client-only decision-support application.

System Benefits

  • Plan laundry schedules more effectively
  • Reduce exposure of clothes to unexpected rain
  • Identify the most favorable drying periods
  • Understand the effect of humidity and wind on drying
  • Receive fabric-specific drying duration estimates
  • Compare conditions across Lagos locations
  • Access the service offline via cached data

Known Limitations

  • Forecast accuracy depends on Open-Meteo's model
  • Drying times are heuristic approximations
  • Actual drying depends on local environment
  • API access requires internet connectivity
  • Notifications need explicit browser permission
  • History stored locally — no cross-device sync
