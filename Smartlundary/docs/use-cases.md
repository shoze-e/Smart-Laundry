# Use Cases

## Use Case 1: Quick Daily Check
- **Actor**: Lagos Resident
- **Goal**: Find out if today is a good day for laundry.
- **Flow**: User opens the app. The dashboard immediately shows the current Drying Score and Best Window for their default location (e.g., Ikeja).
- **Result**: User decides to wash clothes at 10 AM based on the recommendation.

## Use Case 2: Planning a Weekend Wash
- **Actor**: Busy Professional
- **Goal**: Decide which day this weekend to wash heavy items (Jeans/Towels).
- **Flow**: User navigates to the **Calendar**. The app displays the next 7 days and highlights the "Best Upcoming Laundry Day" (e.g., Saturday).
- **Result**: User schedules their laundry for Saturday morning.

## Use Case 3: Precise Estimation for Different Fabrics
- **Actor**: Careful Washer
- **Goal**: Know exactly how long a load of silk will take vs a load of jeans.
- **Flow**: User navigates to the **Planner**. They select 'Silk', 'Hand Wash', and 'Small Load'. The system returns an estimate of 1h 45m. They change to 'Jeans', and the estimate jumps to 4h 30m.
- **Result**: User manages their time appropriately based on the fabric.

## Use Case 4: Evaluating Area Weather
- **Actor**: Person traveling or moving within Lagos
- **Goal**: See if Lekki has better drying weather than Yaba right now.
- **Flow**: User navigates to **Compare**. The app fetches weather for all 6 predefined Lagos areas and ranks them.
- **Result**: User sees that Yaba has less rain risk than Lekki today.
